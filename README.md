# Ashwin Portfolio

A responsive, single-page portfolio for Ashwin, an 18-year-old student at Jain University.

## Preview

Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## Personalize

Update these details in `index.html`:

- Email in the contact button
- LinkedIn and GitHub URLs in the footer
- Add project cards in the selected work section
- Add skills, achievements, or a major if you want them included
